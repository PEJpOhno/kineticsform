rxnfit.expdata_fit module

Estimate unknown rate constants from experimental concentration trajectories.

Minimizers in scipy.optimize drive repeated ODE integrations through rxnfit.solver_backend.solve_ode(); see there for LSODA / numbalsoda behavior and SciPy fallbacks.

class rxnfit.expdata_fit.ExpDataFit(builded_rxnode, df_list, t_range, method='RK45', rtol=1e-06, df_names=None)

Bases: object

High-level façade over pooled least-squares fits and post-fit replay.

Internally drives solve_fit_model_multi() and exposes helpers compatible with RxnODEsolver.

run_fit(p0, opt_method='L-BFGS-B', bounds=None, verbose=True, use_log_fit=False, lower_bound=None)

Optimize rate constants via scipy.optimize.minimize().

Parameters:

  • p0 – Sequence aligned with symbolic keys or explicit name→value mapping. Log-space mode rejects non-positive entries.

  • opt_method – SciPy method string forwarded unchanged.

  • bounds – Box constraints for linear mode; superseded under log-fit.

  • verbose – Toggle progress printing.

  • use_log_fit – Optimize log(k) internally while exposing linear k.

  • lower_bound – Optional shared positivity floor (mode dependent).

Returns:

(OptimizeResult-like, param_info, metrics_dict).

Raises:

ValueError – Invalid seeds, bounds, or incompatible log guesses.

rxnfit.expdata_fit.solve_fit_model(builded_rxnode, fixed_initial_values, t_span, method='RK45', rtol=1e-06)

Build f(t, *params) that predicts species trajectories during fitting.

Bare symbolic rate constants (Symbol) are optimized via params; every other rate_consts_dict entry (numbers, expressions, etc.) stays in the merged constants dict passed to the RHS. fixed_initial_values are fixed ICs.

Parameters:

  • builded_rxnode – Configured reaction network.

  • fixed_initial_values – Species IC vector aligned with function_names.

  • t_span – Global integration window covering every experimental time.

  • method – Passed through to solve_ode().

  • rtol – Relative tolerance for integrations.

Returns:

functools.partial wrapping _eval_ode_fit() plus a param_info dict attached as attribute param_info.

Raises:

ValueError – Wrong IC length versus species count.

rxnfit.expdata_fit.solve_fit_model_multi(builded_rxnode, df_list, t_span, method='RK45', rtol=1e-06, df_names=None)

Prepare multi-experiment residuals sharing one kinetic parameter vector.

Each DataFrame yields its own (y0, t0); integrations stop at t_span[1].

Parameters:

  • builded_rxnode – Configured reaction network.

  • df_list – Homogeneous experimental tables (time + species columns).

  • t_span – Global window enclosing every observation time.

  • method – Passed to solve_ode().

  • rtol – Relative integration tolerance.

  • df_names – Optional labels; see _resolve_df_names().

Returns:

(residual_func, param_info, fit_ctx) where residual_func(params) returns the summed squared error and fit_ctx backs plotting helpers.

Raises:

ValueError – Empty df_list or invalid column layout.
